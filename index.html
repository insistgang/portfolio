CASE 01 / Agent 安全

神盾 AEGIS · Agent 工具调用安全网关

问题
外部文档或工具描述可能把 Agent 从原始任务引向敏感文件、命令执行与数据外发，仅靠模型自我约束不足以控制工具副作用。
个人职责
规则引擎与审计设计；聚焦工具执行前的三态判定、来源关联和脱敏留痕，不把整个安全系统的协作成果归为个人独立交付。
技术决策
  • 由确定性规则执行放行、询问或阻断，模型输出不直接取得执行权限。
  • 多上游 MCP 按来源隔离；SQLite 保存策略编号、证据下标与影响链路。

可核验证据

  • 受控工具攻防对照报告 ↗

    包含协议、固定轨迹、真实模型结果及原始记录索引；固定轨迹效果不能当作自主攻击成功率。

  • SQLite 审计实现 ↗

    可检查写入前脱敏、会话与审计记录存储、JSON 导出的具体实现。

能力边界

公开演示为归档案例回放；受控沙箱不等于企业部署。历史评测未在本轮重跑，不作全面安全或审计不可修改保证。

CASE 02 / AI 智能体系统

基于多智能体协同的 AI 技术知识库管理系统

问题
收藏的技术链接难以持续整理，模型生成的摘要也不能未经审核直接当作可靠知识入库。
个人职责
独立设计与开发个人 AI 技术知识库，组织采集、分析、审核与归档，并提供 MCP 查询；不与竞赛威胁情报库混写。
技术决策
  • 以九节点 LangGraph 状态图表达流程；审核不通过进入有界修订，超限转人工标记。
  • 五维审核分数由代码加权计算，归档保留来源；MCP 将查询能力与采集链路分开。

可核验证据

  • 九节点状态图与分支实现 ↗

    检查 review → organize / revise / human_flag 的分支与修订回路。

  • 审核评分与门禁实现 ↗

    检查五维权重、通过阈值与评分处理，而非仅凭架构图判断能力。

能力边界

当前自动采集主线是 GitHub；HN、arXiv、RSS 不写成已交付数据源。公开 Dashboard 展示归档结果，不代表浏览器可在线启动采集或所有条目已人工复核。

CASE 03 / 多模态检索

视频画面内容检索平台

问题
无声录屏缺少可搜索的内容索引，人工回看成本高；长时间分析任务还需要在失败和进程重启后保留处理状态。
个人职责
视频检索平台设计与开发，围绕 FastAPI 后端、React 检索界面和任务处理链路组织实现；不将源码能力或历史描述升级为未经验证的性能成绩。
技术决策
  • FFmpeg 抽帧与去重，按 quick / two_stage / deep 分阶段处理，再将分析文本写入 SQLite FTS5。
  • 任务状态落入 SQLite；启动时恢复待处理任务，失败任务通过接口重试，不只依赖进程内队列。

可核验证据

  • 持久化队列与恢复实现 ↗

    可检查任务入库、状态更新、启动恢复与 worker 调度。

  • 项目运行与配置说明 ↗

    列出前后端、FFmpeg、模型模式与鉴权配置，区分真实处理和 UI 调试。

能力边界

公开站点仅为静态演示。真实处理需启动后端、安装 FFmpeg 并配置模型服务；FTS5 是全文检索，不宣称任意语义召回、毫秒级性能或多卡吞吐。
